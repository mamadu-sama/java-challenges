## Executar o desafio 01

É necessário um JDK instalado:

```bash
cd desafio-01-gorjeta
javac Main.java
java Main
```

O programa pede o valor da conta, o número de pessoas e a percentagem de gorjeta, e calcula o total e o valor por pessoa.

**Limitações conhecidas:** ainda não valida valores negativos, um número de pessoas igual a zero nem percentagens fora das opções do enunciado. Esta versão foi criada para praticar `Scanner`, cálculos e formatação.
